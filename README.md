# AI-Learning

## 项目简介

本项目是一个统一的深度学习学习仓库，旨在将零散的深度学习学习项目集中管理。

今后所有与深度学习相关的学习项目（论文复现、模型实现、实验记录等）都将以子文件夹的形式在本仓库中创建与维护。

## 目录结构

```
AI-Learning/
├── README.md          # 项目说明
└── <project-name>/    # 各深度学习子项目（按需添加）
```

## 使用方式

每个子项目独立存放在各自的文件夹中，文件夹名称应简洁地描述该项目的主题或内容。每个子项目建议包含独立的 `README.md` 以说明该子项目的目的、方法与结论。

## 涵盖方向（规划中）

- 神经网络基础（MLP、CNN、RNN 等）
- 经典模型复现（ResNet、Transformer、BERT 等）
- 计算机视觉
- 自然语言处理
- 生成模型（GAN、VAE、Diffusion 等）
- 强化学习
